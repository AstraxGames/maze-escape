# Maze Escape 🏃‍♂️💨

# 

# Maze Escape is a fast-paced, 3D multiplayer labyrinth evasion game built with web technologies and packaged for the Windows desktop. Developed by AstraX Games, it features procedurally generated mazes, real-time MMO sessions, and intense 1v1 PvP combat.

# ✨ Features

# 

# Procedural Labyrinths: Never play the exact same maze twice. The game generates a new labyrinth dynamically based on the current level.

# 

# Massive Multiplayer Online (MMO): Drop into a 30-player open session, leave spray paint tags, use voice chat, and race to the finish line.

# 

# PvP Arena (1v1): Challenge players to real-time duels. Equip your melee weapons (Knife, Bat, Sword, Chappal) and fight to 15 points.

# 

# AstraX Cloud Network: Create an AstraX ID to permanently save your level progression, unlocked cosmetics, and friends list across any device.

# 

# Custom Engine: Built from scratch using Three.js for rendering and Tone.js for atmospheric, algorithmic background music and SFX.

# 

# Auto-Updating: The desktop client automatically checks for new releases and updates seamlessly in the background.

# 

# 🎮 How to Play (Windows)

# 

# Navigate to the Releases page.

# 

# Download the latest Maze Escape Setup X.X.X.exe file.

# 

# Run the installer. (Note: You may need to click "More Info" -> "Run Anyway" on the Windows Defender SmartScreen popup).

# 

# Launch the game from your desktop. Future updates will download automatically!

# 

# ⌨️ Controls

# 

# W, A, S, D - Move

# 

# Mouse - Look around

# 

# Space - Jump

# 

# Shift (Hold) - Sprint

# 

# C (Hold) - Crouch / Sit

# 

# F / G - Spray Paint (Tick / Cross)

# 

# E or Left Click - Melee Attack (PvP Arena Only)

# 

# V - Toggle Camera (1st Person / 3rd Person)

# 

# N - Toggle Fly Mode (Developer Only)
